# go-voice website

Static, Simplified Chinese product and download site for the `go-voice` macOS application, served from Cloudflare Workers static assets at `go-voice.yzsaas.net`.

- `public/`: site files. `img/app.webp` is the application screenshot and `img/ai-passport.webp` the FoloToy AI Passport hardware photo; icons are generated from `gui/resources/icon.png`.
- `public/img/ai-passport-purchase.jpg`: full-resolution purchase image copied from `assets/images/ai-passport-purchase.jpg`, with its WeChat mini-program code intact. The purchase section links to the full image and https://ai-passport.folotoy.cn/; prices follow the current shop listing.
- `public/data/releases.json`: generated by the sync script and ignored by Git; do not edit it by hand.
- `scripts/sync-releases.mjs`: reads published `go-voice-v*` GitHub releases of `vfasky/my-ai-audio` for the DMG and `SHA256SUMS.txt` links, and takes the release notes from the matching `## <version>` sections of [gui/docs/CHANGELOG.zh_CN.md](../gui/docs/CHANGELOG.zh_CN.md). The website renders Chinese only; GitHub release documentation keeps its existing language conventions. Set `GITHUB_TOKEN` to avoid API rate limits.
- The vocabulary section describes the default-enabled Common and IT packs, their 96,336 and 12,854 term counts, independent personal vocabulary, controls and remote-processing boundaries. Keep these facts aligned with the application and `gui/internal/wordlists/data/manifest.json`.
- `cloudflare.config.ts`: Worker name, assets handling and the custom domain, deployed with the `cf` CLI.

## Release flow

After a `go-voice` release is published on GitHub:

```sh
cd website && bun install && bun run deploy   # sync + cf deploy
```

Local preview: `bun run sync`, then `bun run dev` and open http://localhost:8787.

Page copy states product facts from the [application guide](../gui/README.md) and [firmware notes](../docs/go-voice-firmware.md). Update the site in the same change when those facts change.
